# 原目录与发布包的区别

## 原目录 `D:\mpv`

这是开发和运行混合目录，除了播放器本体，还包含：

- GUI 源码、PowerShell 和旧版 BAT 启动脚本
- VapourSynth/模型安装工具和构建工具
- 测试副本、备份、文档和本机维护文件
- 本机 TensorRT engine、缓存或之后生成的运行状态

适合继续维护，不适合直接压缩发给别人。

## `发布包`

这是从原目录复制出的便携运行副本，只保留：

- `MPV-GUI.exe`、`mpv.exe` 和运行时 DLL
- `portable_config`、VapourSynth、RIFE/Real-ESRGAN 运行脚本
- CUDA/TensorRT 运行库和模型
- 必要的 Python/VapourSynth 文件

它不依赖 `D:\mpv` 这个路径。解压到任意目录后，双击其中的 `MPV-GUI.exe` 即可。

## 不应删除的内容

发布包中的 `mpv.exe`、`portable_config`、`vs-plugins`、`Lib`、`Scripts`、`vs-coreplugins`、`vsmlrt-cuda` 和模型文件都是运行所需内容。不能只复制 `MPV-GUI.exe`。
